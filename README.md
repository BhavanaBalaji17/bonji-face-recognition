# Bonji Skin AI

Design a modern, premium, and fully responsive frontend for Bonji AI Skin Analysis, an AI-powered facial skin analysis tool that perfectly matches the branding and aesthetic of the Bonji website (https://bonji.in/). Use pastel yellow as the primary color, complemented by warm cream, ivory, soft white, muted beige, and subtle earthy green accents to create a fresh, clean, and welcoming interface. The design should feel minimal, luxurious, and trustworthy, with rounded corners, soft shadows, elegant typography, gentle gradients, and smooth animations. Create a landing page with the Bonji logo, a large heading reading "AI Skin Analysis", and a short description inviting users to upload a selfie or use their camera for a personalized skin assessment. Include two prominent rounded buttons: "Upload Image" and "Use Camera", styled in Bonji's pastel yellow with subtle hover effects. After an image is uploaded, display it inside a beautifully designed preview card while showing an elegant animated loading indicator during analysis. Once complete, present a clean dashboard highlighting detected skin concerns such as acne, pigmentation, redness, dark circles, pores, oiliness, dryness, fine lines, hydration, and overall skin health using modern cards, circular progress indicators, and confidence percentages. Below the analysis, showcase a "Recommended Bonji Products" section with premium product cards containing product images, names, short descriptions, key benefits, and a pastel yellow "View Product" button. Use soft botanical illustrations or abstract organic shapes in the background to reinforce Bonji's natural skincare identity without cluttering the interface. The overall experience should feel calming, premium, intelligent, and user-friendly, with seamless responsiveness across desktop, tablet, and mobile devices, creating an interface that looks like it was designed as a native feature of the Bonji website rather than a separate application.
